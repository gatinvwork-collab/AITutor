# ИИ-репетитор — AITutor

Настольный ИИ-репетитор для учеников 7-го класса: математика, информатика и физика. Целевая поставка MVP — Windows 10/11 x64 Portable с локальными зашифрованными данными и родительским контролем.

**Стадия:** системное проектирование. Приложение ещё не реализовано; сборки и тестов исполняемого продукта пока нет.
