Репозиторий: https://github.com/gatinvwork-collab/Tutor-AI. Для прежнего клона: `git remote set-url origin https://github.com/gatinvwork-collab/Tutor-AI.git`.

Настольный ИИ-репетитор для учеников 7-го класса: алгебра, геометрия, информатика и физика. Целевая поставка MVP — Windows 10/11 x64 Portable с локальными зашифрованными учебными данными и родительским контролем. По решению заказчика имена и роли доступны в открытом локальном списке для выбора профиля при входе.

## Запуск

Независимое QA обнаружило четыре дефекта в 0.3. Они исправлены и перепроверены в 0.3.1 на исходниках и готовом exe: [исходный отчёт](docs/qa-report-2026-10-26.md), [протокол исправлений](docs/qa-verification-0.3.1.md). Схема базы остаётся 3; история сохраняется без массовой перезаписи.

Последующий [независимый повторный QA](docs/qa-report-0.3.1-retest-2026-10-26.md) подтвердил эти исправления и обнаружил новые QA-005–QA-008 в таймере и импорте. В 0.3.2 реализован [соответствующий пакет](docs/qa-remediation-requirements-0.3.2.md); длинный текст отклоняется с предложением разбить задание по явному решению заказчика. История сохраняется, схема остаётся 3.

Готовая локальная Windows-сборка: `dist/Tutor-AI-0.5.0a4.exe` (бинарные файлы не хранятся в Git). Прежний exe сохранён отдельно. Данные создаются в `app-data/` рядом с exe. Закройте прежнюю версию перед запуском новой с той же папкой данных. При первом успешном входе база 0.1/0.2 обновится с сохранением зашифрованного снимка; до этого единственного входа старый список может ещё показывать ID. Для запуска из исходников используйте Python 3.13 x64 и отдельное виртуальное окружение:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe main.py
```

В PyCharm следует использовать настроенный интерпретатор проекта. Для первой настройки создайте профиль родителя и сохраните ID/ключ восстановления отдельно. Добавьте ученика, затем настройте семейное подключение к ИИ. Войдите в профиль ученика, выберите предмет и тему. Для Ollama предварительно нужны запущенный сервер и установленная модель. Для облака нужны собственные действующие ключи и родительские разрешения.

Для повторной сборки:

```powershell
.\scripts\Build-Portable.ps1 -PythonExecutable .\.venv\Scripts\python.exe
```

Если локальная политика Windows запрещает ps1, выполните сборку напрямую, не меняя политику:

```powershell
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --onefile --windowed --name Tutor-AI-0.5.0a4 --icon "$PWD\ui\assets\Tutor-AI.ico" --add-data "$PWD\ui;ui" --specpath build --workpath build\pyinstaller-053 --distpath dist main.py
```

Тесты используют только синтетические профили; запросы к платным сервисам не выполняются:

```powershell
New-Item -ItemType Directory -Path build -Force
.\.venv\Scripts\python.exe -m pytest -q --basetemp=build/tests-local
.\.venv\Scripts\python.exe -m tests.gui_smoke
.\.venv\Scripts\python.exe -m tests.gui_feedback_03
```

Подробности эксплуатации: [руководство](docs/user-guide.md). WebView этой версии основан на Qt WebEngine; [отличия от предложенного стека](docs/adr-0001-python-webview.md).
