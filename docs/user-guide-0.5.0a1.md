# Учебный процесс в предварительной 0.5.0a1

Для испытаний используйте копию Portable-папки. Это предварительная версия с [незавершёнными пунктами](implementation-0.5.0a1.md), а не замена принятого полного выпуска. Обновление переводит данные в схему 4; возврат описан в том же документе.

## Программа и учебник

1. Откройте «Учебный процесс» либо «Учебник и программа». Нажмите «Загрузить программы и работы», выберите предмет. Родитель сначала выбирает ребёнка в общем списке.
2. Разверните карточку учебника. Исправление реквизитов сохраняет действующую программу; отметку замены издания включайте только при реальной замене. Родитель сохраняет сразу, ученик отправляет предложение. ИИ-оформление названия — отдельная подсказка и не меняет факты самостоятельно.
3. В карточке источника найдите книгу по реквизитам либо укажите публичную HTTPS-ссылку. Для книги без источника можно ввести программу вручную. Состояние сетевой задачи и найденный кандидат находятся внизу страницы; «Обновить состояние» перечитывает результат.
4. Для ручного списка каждая строка имеет вид `Название темы | Первый навык; Второй навык`. Это учебные навыки, например «Преобразовать обе части уравнения; Проверить корень подстановкой». Сохраните кандидат. Родитель просматривает темы и источник и отдельно подтверждает публикацию в запросах.
5. Укажите текущую тему. Сам выбор не даёт процента освоения. Пройденные темы отправляются отдельным списком и требуют отдельного решения родителя.

При отсутствии сети/подключения сохранённые реквизиты и ручная программа остаются доступны. Неполное или нерелевантное оглавление не следует отмечать как проверенное полное издание.

## Диагностика и решение родителя

1. По опубликованной программе подготовьте подборку. Пока выполняются генерация и ИИ-проверка, можно переходить по меню и сохранять локальные данные.
2. Родитель смотрит **конкретные** вопросы, эталоны и критерии и отдельно утверждает подборку. Это не проверяет будущие ответы ребёнка.
3. Ученик выбирает утверждённую подборку и цель: тема — 8 обязательных + 2*, предмет — 27 + 3*. Сложный вопрос можно явно пропустить. При недостатке готовых заданий план не создаётся, вместо фиктивного теста предлагается подготовить банк.
4. Ответ и необходимые шаги сохраняются до обращения к ИИ. Исправленный ответ хранится новой версией; основание оценки — первый самостоятельный. Можно приостановить попытку и продолжить позже.
5. C — проверено верно, W — проверенная ошибка, U — принято, но не проверено, S — нет принятого ответа. P относится только к C+W; K показывает проверенное покрытие обязательной части. При отсутствии проверенных данных P не равен нулю — он отсутствует.
6. При U родитель открывает исходный ответ и критерий в карточке попытки, выбирает вердикт и пишет обоснование и область проверки. Решение пересчитывает результат той же попытки, а не создаёт новый ответ. ИИ-анализ без независимой проверки требует такого review.
7. Скрининг предмета никогда не подтверждает освоение темы. Точечная диагностика подтверждает только при полном проверенном покрытии, самостоятельности, отсутствии U/S и P≥80%. Проверенные ошибки остаются основаниями дальнейшего контроля.

## Решение домашней работы

1. В «Проверке ДЗ» откройте/загрузите учебный процесс и создайте работу по выбранному предмету.
2. Прикрепите фото/файл. Сохранённый оригинал зашифрован; для изображения доступно «Посмотреть оригинал». Можно прикреплять следующие страницы той же работы.
3. Для OCR GigaChat родитель отдельно включает разрешение фотографий в настройках провайдера. Обычное разрешение текста документов его не заменяет. Текстовый ручной путь работает без OCR.
4. После OCR или ручного ввода проверьте текст и формулы по оригиналу, отметьте подтверждение и сохраните версию. Поддерживаемые TeX-формулы отображаются локально; сложный неподдерживаемый исходник остаётся читаемым текстом.
5. Выберите «Проверить полное решение», «Дать подсказку» или «Продолжить диалог». Уточнение относится к той же работе. Фото после замечания и исправления сохраняются новыми версиями, прежние не стираются.
6. Результат ИИ не называется независимой проверкой. Формальный анализ сообщает точную область, например равносильность поданных линейных переходов, и не доказывает всю рубрику задачи. Журнал содержит отправленный учебный контекст и ответы, но не API-ключи.

Файл — до 8 МиБ, изображение — до 25 Мп, PDF — до 30 страниц. Текст версии/решения — до 30 000 символов; длинный сетевой контекст тоже может потребовать разделения. Приложение сообщает отказ вместо молчаливого усечения; сохранённые версии и история остаются.
