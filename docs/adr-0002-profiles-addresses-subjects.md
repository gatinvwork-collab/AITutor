# ADR-0002. Метаданные входа, сетевой адресный каталог и предметы 7-го класса

Дата: 25.10.2026. Статус: реализовано для 0.2 на основании согласованных требований.

## Открытые имена и роли

Заказчик разрешил открытый локальный список имён и ролей. В контейнере формата 1 добавлен `directory` версии 1: только `id`, `name`, `role`. Он атомарно записывается вместе с зашифрованным payload и обёртками; секреты, адреса, школа и связи в directory отсутствуют.

`directory_mac` — HMAC-SHA256 с ключом данных и отделённым назначением `directory-v1`. Проверка возможна после ввода пароля. До неё публичные подписи не считаются авторитетными полномочиями. Нативный слой всегда получает роль из расшифрованной БД. Подмена подписи обнаруживается после входа, список восстанавливается по БД; повреждение только этого списка не блокирует возможность выбора профиля по ID. Это не обещание достоверности неподписанного имени на экране до разблокировки.

Имена новых событий аудита находятся в зашифрованном payload. UUID автора/цели не меняются при переименовании. Для старых событий текущее имя разрешается по ID, историческое не выдумывается. Для удалённого/недоступного профиля UI выводит нейтральную подпись.

Этот ADR заменяет положение ADR-0001/целевой архитектуры о запрете любых открытых имён. Исключение ограничено согласованным минимумом, остальные требования шифрования сохраняются.

## Адреса

Интернет-поиск разрешён заказчиком, платные сервисы/подписки не подключались. `AddressDirectory` обращается по HTTPS только к фиксированному Photon endpoint, без редиректов, с ограничением ответа/тайм-аута. Предельная частота — один новый HTTP-запрос в секунду, одинаковый результат кэшируется на 15 минут, UI ждёт 1150 мс после ввода. Просроченные результаты прежнего запроса/региона отбрасываются в UI.

Регионы ищутся в слое state, города — structured search по выбранному региону. Из ответа отбрасываются записи чужой страны/региона; одноимённые населённые пункты показывают адресный контекст. ID имеют namespace типа записи и OSM type/ID; отдельно хранится ID региона. Нативный слой принимает только согласованную пару из ранее полученных им записей, не доверяет присланным названиям. При ручном вводе используется `manual_unverified`. Старые строки автоматически не сопоставляются по сети.

Источник не является ФИАС и не гарантирует исчерпывающего охвата. Публичный Photon допускает ограниченное использование для пилота; при расширении необходим пересмотр сервиса/развёртывания и условий данных. [Документация и условия](https://github.com/komoot/photon), [API](https://github.com/komoot/photon/blob/master/docs/api-v1.md), [OpenStreetMap attribution](https://www.openstreetmap.org/copyright).

## Предметы, контексты и миграция

Новый каталог 7-го класса содержит algebra/geometry/physics/informatics. Старые ID тем math-* сохраняются, их текущая принадлежность — algebra. Исторические subject/program_snapshot не переписываются; текущая агрегация использует отдельное соответствие. Учебники хранятся по ключу `student:subject`, прежние общие записи остаются архивными.

Схема БД повышена до 2. Миграция после успешной расшифровки сохраняет оригинальный зашифрованный контейнер, отмечает старые адреса/назначения и добавляет предметную классификацию, не меняя counters/events. Контейнер записывается атомарно. Восстановление старого backup выполняет эту же миграцию в изолированном staging до публикации.

Для ДЗ требуются сохранённый владелец, явно подтверждённый предмет и совместимая либо неизвестная тема. Текст/файл сохраняются при смене предмета; уже использованная работа клонируется с новой AEAD-привязкой оригинала и без переноса результата. Чужой/иной активный контекст не переиспользуется. Python-анализ принимает ID работы и нативно проверяет её предмет и владельца. Обычные учебные режимы и ДЗ используют разные пути создания сеанса.
