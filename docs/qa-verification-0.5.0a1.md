# Протокол предварительной версии 0.5.0a1

Дата: 28.10.2026. **Полный пакет A01–A20 не принят**, список оставшихся работ: [реализация и обновление](implementation-0.5.0a1.md). Испытания синтетические, без открытия рабочих баз заказчика. Исходный релиз — 0.4.1 (`2ba1ca7`), целевая схема — 4, формат контейнера/backup — 1.

## Выполненные проверки

- Полный нативный набор окончательного исходника: **239 passed**, 145,55 с, без исключения тестов. Проверены прежние роли/профили/темы оформления, шифрование, документы, время, история и перенос; новые CWUS, точные 80%, покрытие навыков, планы 8+2/27+3, обязательные темы 0/1/2/3/13/14/15/16, review и ротация, ACL, идемпотентность, Q9, отмена/stale, откат записи, период исключения, предпросмотр оригинала, фильтр нерелевантных источников и точность длинных десятичных чисел. Этот прогон выполнялся параллельно сборке; его длительность не является замером отклика приложения.
- Старые тестовые фабрики теперь удаляют более новые таблицы и маркеры при создании фикстур 1/2. Проверки исторических значений сохранены; конечная ожидаемая схема изменена с 3 на 4. Сохранённые исторические QA-доказательства не переписывались.
- Истинный Qt WebView, исходники: **30 проверок** — назначение, ручной кандидат/публикация, генерация на подменённом провайдере, отдельное одобрение подборки, план темы, исходный ответ/U, пауза, версии работы и журнал, родительский review, два дизайна × три темы, отсутствие горизонтального переполнения, сохранение узла меню, локальная дробь MathML и отсутствие HTML/XSS. Сетевой провайдер в этом сценарии синтетический.
- GigaChat transport с `httpx.MockTransport`: OAuth, multipart purpose=general, attachments, удаление файлов при успехе и ошибке. **Не живой тест GigaChat и не оценка качества OCR.** TLS не отключался. Протокол сверялся с [официальной документацией](https://developers.sber.ru/docs/ru/gigachat/guides/working-with-files).
- Загрузчик: запрет HTTP/file URL/credentials/нестандартного порта и private/loopback/link-local/multicast DNS. Публичный поиск дополнительно запущен без персональных данных; сервер вернул нерелевантные результаты про карты. Добавлен фильтр соответствия запросу и отдельный тест. Успешный HTTP не считается идентификацией программы; качество поиска точного издания не принято.
- Последняя фикстура создаётся реальными зафиксированными исходниками **0.4.1**, содержит двух родителей, двух детей, PERS с заведомо синтетическим ключом, две зашифрованные исходные работы, историю, модель знаний, уведомление и старый backup. Секреты фикстуры остаются в `build/`, не публикуются в доказательствах.

## Ресурсы и ограничения испытаний

Проба большого снимка у лимита 256 МиБ **пропущена**: до запуска доступно около 2,50 ГБ RAM, меньше установленного для этой пробы безопасного минимума 4 ГБ. История ради освобождения места не удалялась. Это не положительный результат capacity/performance-приёмки. Нативные fault-тесты проверяют отдельный отказ записи и сохранность предыдущего состояния; они не заменяют расширенную аварийную матрицу из постановки.

Первый итоговый прогон дал 235 passed / 1 failed: ZoneInfo не имел базы часовых поясов Windows. Исправлено на QTimeZone; следующий полный прогон — 237 passed (включая добавленный предпросмотр). Первая упаковка с относительным путём `ui` не завершилась; окончательная сборка использует абсолютные пути к зафиксированным ресурсам.

После добавления проверки нерелевантных результатов — 238 passed. Ruff и `node --check` проходят. Испытание exe повторяется после последней пересборки; итоговый SHA должен совпадать с manifest.

Затем исправлено чтение десятичных литералов: Fraction строится из исходной записи, не из округлённого AST float. Для числового формального метода недопустима склейка нескольких `x=`. Итоговый набор — 239 passed. Закрытие SQLite дополнительно сериализовано с публикацией фонового результата.

Окончательный exe: **30 проверок учебного интерфейса**, **5 проверок обновления через UI**, **10 нативных проверок обновлённой копии**; источник 0.4.1 не изменён. Stub-сервер был только на loopback, живые платные модели не вызывались. Обычный запуск без DevTools из `C:\Windows` завершён с кодом 0; изображение и `app-data` созданы рядом с тестовым exe. Оба результата сверяются с одним SHA256 в manifest.

Скриншоты исходников относятся к более раннему UI-прогону; окончательные `exe-*.png` и `smoke.png` относятся к хешу готового exe. Их нельзя использовать как измерение физической задержки изображения.

## Окончательные артефакты

Идентификация, SHA256 и результаты готового exe фиксируются в [manifest.json](evidence/learning-0.5.0a1/manifest.json). В этот каталог включаются только протоколы, скриншоты тестовой семьи и исходники; базы, ключи, recovery и синтетические пароли туда не копируются. До появления завершённых результатов exe одна успешная сборка не считается его функциональной проверкой.

Содержательный корпус всех тем, живые модели/рукопись/источники, полная матрица отказов и не завершённые функции из статуса реализации остаются обязательными для полного выпуска. Численных гарантий качества модели и отклика на целевом ПК этот протокол не устанавливает.
