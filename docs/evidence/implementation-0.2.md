Дата: 25.10.2026. Данные синтетические; пользовательская база не открывалась и не мигрировалась. Основание: [семь замечаний](../user-feedback-requirements-0.2.md), [описание релиза](../release-0.2.md).

- Зависимости: [requirements-lock.txt](../../requirements-lock.txt), без добавления новых пакетов для 0.2.
- Файл: `dist/AI-Tutor-0.2.exe`, **243 385 673 байта**.
- SHA-256: `F395209A022782FDE2F980E46AF87141BB9983D1D9B820C3221EF254497E9CF4`.
- Сборка из локальных незакоммиченных исходников; прежний `dist/AI-Tutor.exe` не заменялся.
- Финальная сборка PyInstaller завершилась успешно. Известное предупреждение неиспользуемого QML assetdownloader plugin не препятствовало проверенному запуску. Работа иных QML-функций этим не утверждается.

## Трассировка семи замечаний

| Требование | Доказательства |
|---|---|
| FB-01 | Unit-тесты запросов, кэша, throttling, ошибки сервиса, ручного режима, согласованности region/city и сохранения ID; GUI-регистрация через подсказки; отдельный живой запрос |
| FB-02 | Unit-тест автора/цели регистрации и старого события без снимков имени; сохранение ID после переименования; GUI проверяет имена автора/цели и русскую подпись |
| FB-03 | Unit-тесты открытых имён/ролей, минимального набора полей, подмены публичной роли без получения полномочий, переименования/удаления; GUI выбирает имя в экране входа |
| FB-04 | Четыре предмета, три геометрические темы/девять численно проверенных задач; независимые учебники; миграция без изменения snapshots/counters/events; GUI переключает алгебру/геометрию |
| FB-05 | Запрет отсутствующего предмета и несовместимой темы до HTTP; запрет чужого активного контекста; предмет в prompt и сеансе; клонирование уже использованной работы с сохранением исходного AEAD-файла; идемпотентный повтор; отказ ИИ без пустого активного сеанса; GUI подтверждает паузу |
| FB-06 | Прямые нативные вызовы с другой работой/предметом/владельцем отклоняются; код не исполняется; GUI показывает Python только для информатики |
| FB-07 | GUI переключает предмет внутри вкладки, видит его темы, сохраняет черновик ДЗ при смене предмета и приостанавливает прежний сеанс перед новой работой |

GUI использует реальный Qt WebView, QWebChannel, SQLite и шифрование; только HTTP-транспорты ИИ и адресного каталога подменены на синтетические. Живой Photon проверен отдельно. Живые ИИ-запросы с четырьмя реальными провайдерами не выполнялись и не засчитываются как пройденные.

## Границы результата

Это регрессионная проверка пакета 0.2 на текущем Windows 11. Windows 10, другой физический ПК, физическое отключение питания, полнота каталогов, независимый security review и педагогический пилот не проверялись. Школьный справочник, официальный ФИАС, OCR/voice input и другие незавершённые требования полного MVP остаются открытыми. Исходный контейнер сохраняется при синтетическом отказе записи; это не эквивалент испытаний всех вариантов потери питания.
