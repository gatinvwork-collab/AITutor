# Доказательства 0.6.0a1

См. [протокол](../../qa-verification-0.6.0a1.md). `manifest.json` содержит хеш exe и 43 производственных файлов, сверенных со снимком сборки. `frozen-source.zip` содержит только производственные исходники, UI и фиксацию зависимостей; пользовательских баз и секретов в нём нет.

JSON и JUnit описывают изолированные синтетические испытания. Полные PDF, базы, ключи восстановления, ответы реальных учеников и API-ключи не включены. В `source-pipeline-fixture.json` распознавание явно обозначено как детерминированная фикстура; `frozen-pdf.json` подтверждает парсинг и растеризацию в exe, а не качество OCR. Физическая проверка финального exe остановлена пользователем Escape и не считается выполненной.
