# Протокол реализации 0.1

Дата: 25.10.2026. Испытания локальные, данные синтетические. Это протокол проверок прототипа; он не заменяет AT-01–AT-38 и не утверждает готовность пилотного MVP.

## Сборка и окружение

- ОС сборки/запуска: Windows 11 x64, `10.0.26300`.
- Python: 3.13.15, виртуальное окружение проекта.
- PySide6: 6.12.0; PyInstaller: 6.22.3.
- Полный набор версий: [requirements-lock.txt](../../requirements-lock.txt).
- Исполняемый файл: `dist/AI-Tutor.exe`; размер **243 365 308 байт**.
- SHA-256: `8406152F47D8A2F9C662BEF7433C09D36DC20A83DD6EDDF5A38142201907A4CE`.
- Сборка создана из локальных незакоммиченных исходников; checksum относится именно к этому бинарному файлу, а не к предыдущему commit репозитория.

Прямая команда PyInstaller завершилась успешно. PowerShell-скрипт сборки на этом ПК не запускается из-за локальной ExecutionPolicy; политика не менялась, сборка выполнена прямой командой Python из README. В ходе анализа PyInstaller выдал предупреждение об отсутствующем QML assetdownloader plugin, не используемом этим UI. Проверенный exe запустился несмотря на предупреждение; это не подтверждает работу других QML-модулей.

## Что покрывают тесты

Шифрование контейнера и повторный вход; неверный пароль; recovery и его ротация; сброс пароля ребёнка; нативные запреты чужого профиля и родительских команд; неподтверждённый родительский доступ; одноразовая привязка второго родителя; revision-конфликты и отсутствие API-ключа в DTO/дисковом контейнере; облачный consent gate до вызова провайдера; подсказки и вклад в знания; идемпотентность; неизвестный формат ответа без штрафа; монотонный лимит/grace; завершённая история; адаптация диагностики и переход тем; исторический снимок программы; backup/restore и неверные данные входа без разрушения текущей БД; откат при синтетическом отказе записи; дроби/единицы; анализ Python без исполнения; четыре HTTP-контракта через MockTransport; secret-free ошибки HTTP; ограничения endpoint; импорт TXT/DOCX и подтверждение; отменённый ответ без создания занятия; запрет обхода времени через ДЗ.

Поиск открытых маркеров в контейнере — полезная отрицательная проверка, но не доказательство криптостойкости. Испытание отказа записи — синтетическое, не физическое отключение питания. Проверки Windows 10, чистой VM и второго компьютера не выполнялись.
