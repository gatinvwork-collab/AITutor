# Проверки реализации 0.3

Дата: 26.10.2026. Среда: Windows 11 x64, Python 3.13.15, PySide6 6.12.0, Qt WebEngine. Использованы только синтетические профили и тестовый ИИ; реальная папка пользовательских данных не открывалась. Сборка и запуск Portable описаны ниже.

## Автоматические проверки

- `pytest -q --basetemp=build/tests-03-final`: **66 passed**, 33,29 с. Включены 53 прежних и 13 новых проверок. Предыдущий запуск выявил ошибку порядка событий аудита; после исправления полный набор прошёл.
- `tests.gui_smoke`: **passed**, каталог `build/gui-96914510`. Реальные окно Qt, WebChannel и формы регистрации с адресными подсказками; проверены имена при входе/в журнале, выбор предмета, ограничение Python информатикой, черновик ДЗ, приостановка и учебный контекст.
- `tests.gui_feedback_03`: **passed**, каталог `build/gui03-9bdf9cc1`, **21 снимок**. Проверены defaults по роли, сохранение собственной анкеты через форму, родительское редактирование, уведомления/прочтение, четыре сочетания дизайна/цвета, отсутствие пустого архива, сброс фильтра при смене ребёнка и переключение системной темы для обоих дизайнов через Qt. Снимки выполняются после отрисовки, а не сразу после изменения DOM.
- Проверка системного режима первоначально выявила отсутствие передачи темы из Qt в CSS media queries; добавлена нативная синхронизация, итоговый GUI-запуск прошёл.
- Статический анализ `ruff check aitutor tests main.py` и `node --check` для `app.js`, `profiles.js`, `addresses.js` выполняются перед выпуском; `git diff --check` проверяет формат изменений.

## Что подтверждено по требованиям

| Группа сценариев спецификации | Проверка и результат |
|---|---|
| U03-01–04, U03-06 | Нативные тесты defaults/сохранения и GUI-переключение дизайнов, цветов и системной темы прошли; четыре ключевых экрана сняты в каждом сочетании |
| U03-05 | Стили содержат фокус, сокращение движения и подложку без blur; основные снимки проверены визуально. Отдельная аппаратная проверка производительности на минимальном целевом ПК не проводилась |
| U03-07–12, U03-15 | Проверены изменение имени/адреса, синхронизация открытого списка, актуальность связей, офлайн-сохранение адресных ID после перезапуска, неизменность учебного снимка; предыдущие адресные тесты проверяют подмену и согласованность |
| U03-13–14 | Нативные ошибки записи откатывают анкету, ревизию, уведомления и открытый список; устаревшая форма получает conflict. Кнопки отмены/перечитывания и подтверждение ухода реализованы в UI |
| U03-16–21 | Нативные данные и GUI подтверждают скрытие пустого архива, предметное соответствие старой математики и сброс архивного фильтра у другого ребёнка; архив определяется до фильтра даты |
| U03-22–25 | Проверены настоящие старые схемы 1/2, зашифрованные снимки, отсутствие изменений исходного контейнера при сбое, сохранение цвета/истории/восстановления, старый backup и перенос данных |
| U03-26–27 | Проверены редактирование связанного родителя и запрет доступа к его другим детям, транзитивному родителю, паролю и анкете после отзыва связи |
| U03-28–31 | Проверены отдельные получатели/прочтение, отсутствие повторных уведомлений при неизменённых полях, атомарный откат, backup/перезапуск, отзыв связи, ученик без родителей и изменения родителем |

Это протокол проверок пакета 0.3, а не утверждение о прохождении всей приёмки MVP. Внешние ИИ-провайдеры не вызывались; OCR, диктовка и остальные ранее открытые функции не входят в эту проверку.
