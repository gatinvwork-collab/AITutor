# Независимое регрессионное тестирование Tutor-AI 0.5.0a1

Дата: 28.10.2026. **Обнаружены три подтверждённых дефекта. Реализованный объём предварительной версии требует исправлений; полная приёмка MVP/A01–A20 не подтверждена.** Для программиста подготовлен [реестр с предусловиями, шагами, фактическим результатом и критериями перепроверки](qa-bug-register-0.5.0a1-2026-10-28.md).

## Объект и основания проверки

[README](../README.md) одновременно описывает опубликованную 0.4.1 и предварительные исходники 0.5.0a1. Основной объект этого прогона — текущая **0.5.0a1, схема 4**, включая регрессию функций прежних выпусков. Готовый `dist/Tutor-AI-0.5.0a1.exe` проверен отдельно. 0.4.1 используется как исходная версия для испытания обновления; весь старый бинарный выпуск заново не аттестовывался.

Прочитаны README, [фактический статус реализации](implementation-0.5.0a1.md), [руководство новой версии](user-guide-0.5.0a1.md), [руководство прежних функций](user-guide.md), постановка A01–A20 и существующие протоколы QA. Заявленные там незавершённые работы не объявлялись выполненными и не подменялись успешными тестами оставшейся части.

Среда: Windows, Python 3.13.15 из настроенного SDK PyCharm `.venv/Scripts/python.exe`, Qt WebEngine из окружения проекта. Полная идентификация, SHA256 исходников, сведения о результатах и пути тестовых копий находятся в [summary.json](evidence/qa-independent-050-2026-10-28/summary.json). Git-основание пакета разработки — `2ba1ca7`; рабочее дерево уже содержит незакоммиченные изменения реализации, поэтому идентификация выполнена также по файлам.

SHA256 exe: `dd818a749ebb4964728432f073e309f8c90c49f96bd5b7017f52b1332eb36ebf`, размер 244 940 670 байт. Контрольные суммы текущих файлов из манифеста выпуска совпали с [манифестом разработки](evidence/learning-0.5.0a1/manifest.json); смешения другой реализации с проверенным exe не выявлено.

Использованы только синтетические семьи и отдельные каталоги `build/`. Рабочие `app-data` не открывались. Платные/живые ИИ, OCR и пользовательские учётные данные не использовались; сетевой транспорт либо подменён, либо направлен на тестовый loopback-сервер. Изменялись только QA-скрипты и отчётные материалы. Код приложения, существующие тесты и exe не исправлялись.

## Как проводилась проверка и разобраны остановки

Основной прогон: `.venv/Scripts/python.exe -X utf8 -m pytest -q --basetemp=build/qa-independent-050-20261028 --junitxml=docs/evidence/qa-independent-050-2026-10-28/pytest.xml`. Выполнялся нативно. Независимые тесты используют новый отдельный basetemp. Настроенный SDK проверялся перед вызовами Python.

Qt/WebView проверялся существующими GUI-harness и собственными сценариями текущих форм. Действия выполнены через JS DOM/forms и настоящий bridge в Qt; в exe — через локальный CDP, не через имитацию реализации в браузерном макете. Это программно инициированные действия, не ручная проверка физической мыши/клавиатуры. Выбор файла в новом импортном сценарии намеренно подменён на три тестовых результата: короткий файл, длинный файл, отмена; дальнейшие импорт и обработчик формы настоящие.

Начальные source GUI-запуски из sandbox не завершили сценарии; через терминал IDE те же модули выполняются. Сохранены `native-attempt-*` и исходные логи. Один поздно завершившийся sandbox-процесс записал свой timeout в общий лог профилей после успешного IDE-прогона; итоговый профильный сценарий повторён с отдельным именем `ide-gui-feedback03-final`, результат успешен. Таких timeout недостаточно для атрибуции приложению. Рабочие пользовательские процессы не завершались.

Три старых GUI-сценария остановились из-за прежних селекторов/ожидаемой версии — [T-050-01 в реестре](qa-bug-register-0.5.0a1-2026-10-28.md). Вместо формального объявления их успешными сохранены исходные неудачные результаты и выполнены адаптированные сценарии. В новой проверке Python сначала было неверное ожидание текста сообщения; ожидание исправлено по фактическому контракту «Синтаксис Python корректен», после чего 12 проверок прошли. Первая попытка exe не нашла Node в PATH терминала IDE; в последующем драйвере указан существующий runtime. Первая версия независимого CDP-сценария ошибочно добавляла `operation_id` к read-only job/attempt/overview; драйвер исправлен, продукт не менялся. Итоговый результат трёх дефектов относится к исправленному сценарию.

## Непроверенные условия и решение о готовности

Живые OpenAI/GigaChat/Qwen/Ollama, платные модели, качество печатного/рукописного OCR, реальные школьные программы/издания и реальная доступность адресного поиска не проверялись. Аудиовывод Windows и наличие русского голоса на машине пользователя не проверены. Нагрузочный предел около 256 МиБ, исчерпывающая аварийная матрица и физический отклик native-окна также не аттестованы. Системная тема проверена средствами Qt-harness, не сменой пользовательских настроек Windows. Пользовательские минутные задержки и ранее отмеченное расхождение native-снимка с DOM нельзя закрывать этими результатами.

Не выполненная разработка из [таблицы предварительной реализации](implementation-0.5.0a1.md), включая полные A05/A06/A08/A09/A11/A12–A17, остаётся открытой работой. Она отделена от трёх новых дефектов уже реализованных путей.

Для передачи программисту приоритет — QA-050-01, затем QA-050-03 и QA-050-02. После исправлений нужно получить успешные независимые тесты, проверить три сценария на пересобранном exe с новым SHA256, обновить устаревшие GUI-сценарии и повторить затронутую регрессию. Успех основного набора 239 сам по себе не является основанием закрыть реестр или принять весь MVP.
