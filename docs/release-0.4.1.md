# Tutor-AI 0.4.1 — навигация, фокус и бренд

Основание: [обращения пользователей](user-feedback-requirements-2026-10-27.md), [независимый QA](qa-user-feedback-2026-10-27.md) и [реестр](qa-user-feedback-register-2026-10-27.md). Подробные результаты и ограничения — в [протоколе 0.4.1](qa-verification-0.4.1.md).

## Что изменилось

- Исправлена **QA-FB-03**: узлы бокового меню больше не удаляются при каждом переходе. Enter/Space оставляют фокус на активированной кнопке, Tab продолжает движение по меню. Выбранный пункт отмечается `aria-current="page"`.
- Перерисовывается содержимое раздела; общий каркас и меню сохраняются в пределах того же авторизованного контекста. После выхода/restore прежний персональный DOM по-прежнему полностью удаляется.
- Проверяется доступность маршрута для роли. Неизвестный маршрут не открывает произвольный экран молча. Вспомогательная анкета подсвечивает исходный раздел; сохранение/отмена возвращают туда, откуда она открыта.
- Во время операции меню доступно для просмотра; поля, повторная отправка, смена ученика и другие конфликтующие действия заблокированы. Завершение запроса не перехватывает более поздний переход. При сохранении изменённой анкеты переход откладывается с понятным сообщением: он не отменяет уже отправленное сохранение. Выход и restore сохраняют обязательную очистку контекста.
- Фоновый таймер не ставит новые задания в занятую нативную очередь. Все команды по-прежнему выполняются последовательно; число ожидающих пользовательских команд ограничено. Учёт времени остаётся монотонным, действуют прежние пределы бездействия и дополнительного времени.
- Добавлена **добровольная диагностика** ожидания очереди, выполнения команд и подготовки DOM/RAF. По умолчанию она выключена; режим не меняет графические настройки.
- Логотип на входе и в боковой панели, значок окна и ресурс exe подготовлены по найденному исходному брендовому листу. ICO содержит 16/24/32/48/64/128/256 px. Русское название, общая палитра, шрифты и значки разделов сохранены. [Правила применения ресурсов](brand-assets.md).

## Статус исходных обращений

**UF-01/02 остаются открытыми.** Задержка 15 секунд/более минуты и переход students → history на безопасных синтетических данных не воспроизведены. Подтверждённая причина потери фокуса — удаление всей разметки `#app`, включая кнопку с фокусом. Возможность накопления таймерных задач при занятом исполнителе устранена, но её связь с конкретной жалобой не установлена.

Измерения click → два RAF не являются измерением фактического появления пикселей на мониторе. Предположения о GPU/драйвере не объявляются причиной; настройки аппаратного ускорения не изменялись. Для точного воспроизведения нужны путь/версия запускаемого exe, масштаб Windows, состояние окна и предшествующая операция.

## Обновление с 0.4.0

1. Закройте старое приложение и сохраните **всю** прежнюю Portable-папку отдельно для возврата.
2. Поместите `Tutor-AI-0.4.1.exe` рядом с существующим `app-data/`. Не создавайте новый профиль и не вкладывайте `app-data` внутрь другого `app-data`.
3. Войдите прежним паролем. Схема остаётся **3**; история, ID, роли, связи, ключевые обёртки, оригиналы и формат `.aitbackup` не преобразуются из-за меню или логотипа.

Существующий встроенный перенос в пустое назначение сохранён. Источник не изменяется, непустое назначение не перезаписывается, действуют прежние блокировки и восстановление после прерывания. Отдельный новый мастер миграции не вводится.

Возврат — запуск сохранённой старой папки. Новые записи автоматически назад не сливаются. Наличие одного старого exe без отдельной копии данных не заменяет резервную копию.

## Как собрать диагностику задержки

Запустите именно новый exe с дополнительным параметром:

```powershell
.\Tutor-AI-0.4.1.exe --diagnostics
```

Выполните проблемные действия, затем закройте приложение. В `app-data/logs/` появится `performance-<дата>-<суффикс>.jsonl`: тип команды, ожидание очереди, длительность, ID раздела, размеры окна/DPR и время подготовки кадра в WebView. Последняя метрика **не** означает физическую задержку монитора. Пароли, ключи, ID пользователей, имена, пути файлов, вопросы и ответы в этот журнал не записываются. Данные никуда автоматически не отправляются. На один запуск журнал ограничен примерно 2 MiB.

Следующий запуск без `--diagnostics` не продолжает сбор. Ошибка записи диагностического файла не блокирует учебную операцию. Исходную базу, ключ восстановления и API-ключи для диагностики отправлять не требуется.

Точные размер и SHA256 финального exe приведены в [манифесте сборки](evidence/user-feedback-fix-0.4.1/build-manifest.json).

Родительский каталог, открываемый карточками из обзора, сохранён как вспомогательный экран с подсветкой «Обзор семьи»; это не добавляет прав на учебные операции.
