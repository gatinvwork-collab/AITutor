# Работа с Tutor-AI 0.4.0

## Первый запуск

Запустите `dist/Tutor-AI-0.4.0.exe` из доступной для записи папки. При переносе копируйте exe и **весь** каталог `app-data/`. Для этого приложения WebView2 не нужен: Qt WebEngine включён в поставку. Первый запуск exe может быть дольше запуска из исходников из-за распаковки ресурсов.

Создайте первый профиль родителя или ученика. При входе показываются имя и роль; одинаковые имена одной роли различаются коротким суффиксом ID. По разрешению заказчика имя и роль хранятся открыто в локальном списке, а остальные данные профиля и история остаются зашифрованы. Полный ID сохраните для восстановления. Пароль — не менее 10 символов; короткий PIN не поддерживается. Ключ восстановления родителя показывается один раз.

Для профиля ученика введите минимум две буквы региона, выберите подсказку, затем найдите и выберите город. Источник — Photon / OpenStreetMap, не ФИАС; API-ключ не нужен. Поиск выполняется через интернет и не передаёт имя, пароль или всю форму. Изменение региона сбрасывает город и школу. При недоступности источника или отсутствии записи включите «Ввести адрес вручную»: форма сохранит значения как неподтверждённые. Школа в 0.3 по-прежнему вводится вручную, отдельный школьный справочник не подключён.

Откройте «Настройки → Мой профиль → Редактировать мои данные», чтобы изменить имя, а ученику — также регион, город и школу. «Отмена» не меняет сохранённые данные. Если анкету уже исправил другой пользователь, нажмите «Перечитать профиль» и внесите изменения в актуальные данные. Открытый список имён обновится вместе с зашифрованной базой; ID, история и связи останутся прежними.

Родитель открывает формы также в «Профили и связи». Доступны связанные дети и родители с общим подтверждённым ребёнком. Редактирование анкеты родителя не даёт доступа к его паролю, ключу или остальным детям.

После самостоятельной смены учеником региона, города или школы каждый связанный родитель видит уведомление в разделе «Уведомления» и счётчик непрочитанных в меню. Прочтение отмечается отдельно каждым родителем; уведомления сохраняются после закрытия приложения. Предварительное согласование анкеты не требуется. Учебники и программы по-прежнему изменяются отдельным запросом с подтверждением.

## Оформление

В настройках независимо выбираются дизайн («Строгий» или «Современная») и цветовая тема («Светлая», «Тёмная», «Как в системе»). Выбор сразу показывается для предпросмотра; нажмите «Сохранить», чтобы оставить его после перезапуска. При уходе без сохранения возвращается прежнее оформление. При создании профиля и обновлении старой базы родителям назначается «Строгий», ученикам — «Современная». Прежний цветовой режим сохраняется. В режиме «Как в системе» приложение реагирует на изменение темы Windows без перезапуска.

## Обновление и семейные связи

Обновление с 0.3.1 до 0.3.2 не меняет SQL-схему 3 и не пересчитывает историческое время. Старые ДЗ, оригиналы и результаты сохраняются. Перед новой проверкой старого файла приложение проверяет извлечение заново; допустимый текст открывается в новой версии работы для повторного подтверждения. Слишком длинный текст отклоняется, а прежняя история остаётся доступной.

Версия 0.3.1 открывает базу 0.3 в той же схеме 3: отдельное преобразование формата не требуется. Исправления архивов и предметной принадлежности применяются при чтении и не удаляют старые записи. Неизвестная физическая тема остаётся в физике; если предмет нельзя достоверно определить, используется группа «Предмет не определён».

При обновлении с 0.1 или 0.2 закройте прежнее приложение и сохраните копию всей папки. Запустите новый exe рядом с прежним `app-data/` и выполните первый вход. Миграция создаст зашифрованный снимок `app-data/backups/before-migration-vN-….aead` и обновит схему до версии 3 с сохранением истории. Не запускайте старое приложение с обновлённой базой; для возврата используйте сохранённую папку старой версии. До первого входа имена профилей версии 0.1 могут ещё отображаться по ID.

Родитель добавляет ребёнка в разделе «Профили и связи». Если первым зарегистрировался ученик, он создаёт первого родителя через настройки. Чтобы связать второго родителя, существующий родитель создаёт его отдельный профиль и одноразовый код для ребёнка. Новый родитель входит со своим ID и паролем и вводит код. Простого создания второго профиля недостаточно для доступа к детям.

## Подключение ИИ

Войдите родителем, откройте «ИИ-провайдеры». Укажите провайдера, доступную модель, секрет и timeout. Ollama должен быть запущен на локальном компьютере; удалённый сервер в 0.1 не поддерживается. Для Qwen выберите endpoint региона своего ключа. GigaChat использует Basic-ключ и scope; при ошибке сертификата настройте доверенный CA Windows, не отключайте TLS-проверку.

Для облачного подключения включите разрешение на передачу учебного текста. Для текста документов/ДЗ требуется отдельное разрешение. Сохраните, выполните «Проверить текстовый запрос». Настройки общие для локальной семьи. Ключ не отображается после сохранения; пустое поле при сохранении того же провайдера сохраняет прежний секрет.

## Занятие

Войдите учеником. Доступны алгебра, геометрия, физика и информатика. На вкладке «Предметы» их можно переключать напрямую; просмотр другого предмета не завершает текущее занятие. При начале новой работы приложение предложит сохранить и приостановить прежнюю. Начало требует рабочего ИИ-подключения, родительской связи и доступного лимита. Модель даёт объяснение, затем следуют задания небольшого встроенного банка. Проверка ответов выполняется независимо от модели в поддерживаемом диапазоне; подсказки уменьшают вклад ответа в оценку освоения.

Геометрия включает три начальные темы: прямые/лучи/углы, смежные/вертикальные углы, треугольники и сумма углов. Угловые ответы вводите с обозначением `°` или словом «градусов». Полная годовая программа ещё не подготовлена. В карте знаний и отчётах есть фильтр предмета. Пустые архивные предметы в нём не показываются. Наличие архива определяется по данным выбранного ученика за всё время, независимо от выбранной недели отчёта. Старые занятия сохраняют подпись «Математика — архив»; известные темы учитываются в фильтре алгебры, неизвестные — в архивной группе, без дублирования результатов.

Учебники назначаются отдельно каждому предмету через запрос ученика и подтверждение родителя. Прежнее общее назначение сохраняется как архивное до нового предметного выбора. В журнале безопасности родитель видит русское название действия, имя/роль автора и отдельный целевой профиль; ID доступны в технических подробностях.

Карта знаний показывает расчётную оценку и уверенность. Это не школьная отметка. Диагностика начинает со среднего уровня банка: успех переводит к следующему уровню, ошибка — к предыдущему. После трёх наблюдений тема завершается; диагностика по предмету переходит к следующей теме. Банк и уровни предварительные и требуют педагогической калибровки.

Сохранённое занятие доступно в истории. При навигации по экранам задание не теряется. «Сохранить и приостановить» останавливает учёт времени. После трёх минут без учебных действий занятие приостанавливается. Родитель задаёт дневной лимит; новый сеанс после него не начинается, текущий получает максимум 15 минут сверх лимита. Ошибки сети не удаляют сохранённую историю.

Кнопка отмены помечает ответ ИИ как отменённый; он не применяется к занятию. Освобождение сетевого ожидания может занять время до ответа или timeout. Отменённый запрос всё равно может учитываться провайдером в расходе.

## Домашние задания

Есть два независимых ограничения: файл — не более **8 MiB**, извлечённый текст — не более **30 000 символов**. Более длинный текст отклоняется с предложением разбить задание; молчаливой обрезки нет. Это относится также к PDF/DOCX. Переводы строк приводятся к LF; длина считается в Unicode-кодовых точках, поэтому emoji вне BMP считается одним символом. Сохраняются прежние ограничения на PDF и распаковку DOCX.

Если при повторном открытии старого файла текст был извлечён заново, проверьте показанную новую версию и снова отметьте подтверждение перед отправкой. Старый результат при этом не изменяется. Если оригинал недоступен, прикрепите исходный файл заново. При ошибке нового импорта или отмене выбора ранее открытая работа остаётся на месте.

Сначала выберите предмет ДЗ. Тему можно указать или оставить неопределённой. Кнопка «Проверить ДЗ по этому предмету» из каталога предварительно выбирает предмет, а общий экран не подставляет скрытую математику. Можно ввести условие и своё решение либо выбрать TXT/PY/CSV/PDF/DOCX/изображение через нативный диалог. Максимум 8 MiB; PDF — до 30 страниц, DOCX — до 32 MiB после распаковки. Оригинал сохраняется зашифрованным. Подтвердите предмет и текст перед отправкой.

Смена предмета сохраняет файл и текст, сбрасывает несовместимую тему и скрывает прежний результат в текущем контексте. Уже проверенная работа остаётся с прежним предметом; новая проверка в другом контексте получает отдельную запись. Текущее занятие другого предмета не используется для ДЗ: сначала приложение предложит его сохранить и приостановить. Файл с заданиями разных предметов проверяйте по частям.

В этой версии картинки и рукопись автоматически **не распознаются**: требуется ручная расшифровка. PDF/DOCX извлекаются как текст/таблицы с предупреждением о возможной потере формул и рисунков. Ответ на произвольное ДЗ выдаёт ИИ; он помечен как не прошедший независимую проверку и не изменяет карту знаний как достоверный успех. ДЗ учитывается в лимите учебного времени.

Блок «Проверить синтаксис Python» доступен только для информатики. Ограничение проверяется также нативным слоем по владельцу и предмету работы. Код не выполняется, доступ к файлам/сети ему не предоставляется. При смене предмета черновик кода остаётся для возвращения к информатике, но не передаётся как код другого предмета.

## Пароли и копии

После успешного восстановления приложение очищает прежний персональный интерфейс и предлагает войти заново. Старый открытый отчёт, файл или черновик не переносится в восстановленную базу из памяти. При ошибке проверки копии текущая база остаётся рабочей. На новом входе доступны только данные и права из выбранной копии.

Связанный родитель сбрасывает пароль ребёнка без удаления истории. Свою учётку родитель восстанавливает на экране входа с помощью recovery-ключа. Перевыпуск recovery аннулирует старый ключ для текущего vault; старые backup сохраняют старые обёртки.

Ручная копия требует отдельного пароля архива. Сохраните этот пароль и учётные данные родителя, действовавшие на момент копирования. При входе родителя создаётся ежедневная автокопия, дополнительно защищённая ключом vault. Эти файлы находятся в `app-data/backups`. Для резервирования от физической утраты компьютера скопируйте их на другой носитель самостоятельно.

При восстановлении введите имя файла из `backups`, пароль архива для ручной копии, ID и пароль родителя **из копии**. Сначала проверяется целостность и возможность входа; затем заменяется текущий vault. Перед заменой сохраняется зашифрованный снимок `.aead`. Ручные копии переносимы с паролем архива и данными входа; автокопии требуют доступа к ключу текущего vault. Отдельного восстановления в пустую установку через UI пока нет.

Удаление текущего профиля не удаляет данные из старых копий. Защита общим ключом не изолирует пользователей от владельца извлечённого мастер-ключа вне приложения.

## Что ещё не готово

Официальный ФИАС и школьный справочник, автопоиск программ, полный учебный каталог, OCR/vision, диктовка, педагогическая калибровка диагностики, нормализованная схема всех сущностей, полный цикл удаления/отзыва ключей и проверка всех AT. Сетевой адресный источник не гарантирует доступность/полноту всех записей; предусмотрен ручной ввод. Озвучивание использует доступный системный голос Windows; его наличие и русский язык зависят от настройки ОС. Текстовый режим работает независимо от озвучивания.


## Переход на Tutor-AI 0.4.0

Поддерживаются прежний app-data рядом с новым exe и встроенное копирование в пустую установку. До обновления сохраните отдельную полную копию старой установки. На первом экране выберите «Перенести данные из прежней версии», укажите корень прежней папки (не сам app-data), проверьте пути и введите прежний пароль. Для отдельного Portable-комплекта отметьте другую пустую папку; перенос из исходников выполняется в текущую папку проекта. При конфликте данные не перезаписываются. После переноса войдите заново. При ошибке используйте очистку незавершённого переноса; после перезапуска можно выбрать целевую папку отдельно. Подробные ограничения, восстановление и возврат: [инструкция 0.4.0](release-0.4.0.md).
