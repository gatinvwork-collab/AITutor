# Tutor-AI 0.5.0a2 — исправления независимого QA

Дата: 28.10.2026. Основание: [требования QA-050-01–03](qa-remediation-requirements-0.5.0a1-2026-10-28.md). Выпуск остаётся предварительным; полный пакет A01–A20/MVP не принят. [Протокол исправлений](qa-verification-0.5.0a2.md).

## Изменения

- **QA-050-01.** Завершение готовой приостановленной A при активной B меняет статус только A. Указатель, idle-отметка и временная база B не сбрасываются. Обычный checkpoint B до операции сохраняется; повтор операции не начисляет время второй раз. Атомарный отказ сохраняет согласованное состояние.
- **QA-050-02.** Контекст ДЗ состоит из исходного решения и последовательных пользовательских запросов/ответов. Из каждого старого вызова извлекается одна новая реплика, а не весь вложенный снимок. Новые записи содержат revision, намерение и происхождение контекста. Исторические версии явно помечаются. Неуспешный/отменённый/устаревший вызов не становится учебным ответом. При превышении 30 000 символов запрос отклоняется до отправки, без усечения и потери журнала/черновика.
- **QA-050-03.** Предмет кнопки «Проверить ДЗ по этому предмету» передаётся новому учебному экрану. Поздняя загрузка не откатывает последующий выбор. Неизвестный предмет требует явного выбора. Черновики разделены по ученику, предмету и форме; после входа другим пользователем они очищаются. Python остаётся доступен только работе по информатике.
- Для старой работы с ошибочным предметом добавлена **явная исправленная копия**. Исходник, его предмет, версии, фото и журнал сохраняются. Копия имеет новый ID, ссылку на исходную revision и неподтверждённый текст; прежние результаты в неё не переносятся. Перед новой проверкой требуется подтверждение.
- GUI-регрессии регистрации/ДЗ, импорта и переноса адаптированы к текущей форме; исторические независимые доказательства не изменялись.

## Обновление и сохранение данных

1. Закройте старое приложение и сохраните отдельную полную копию Portable-папки с `app-data`. Для проверки предварительной версии сначала используйте копию.
2. Положите `Tutor-AI-0.5.0a2.exe` рядом с нужной `app-data`. Папка данных определяется относительно exe, независимо от текущего каталога.
3. **С 0.4.1:** сохраняется проверенный маршрут схемы 3→4 с зашифрованным снимком перед изменением. Для более старых поддержанных схем действует прежний полный маршрут.
4. **С 0.5.0a1:** SQL-схема остаётся 4, формат AEAD и `.aitbackup` — 1. Массового преобразования истории нет. Дополнительные поля контекста записываются только в новые вызовы; старые запросы не переписываются.
5. Активное при неожиданном закрытии занятие требует явного продолжения после входа. Уже пропущенное время не восстанавливается по настенным часам. Старые ошибочные предметы и оценки не меняются автоматически.
6. Пароли/recovery, связи, PERS и прежние согласия сохраняются; разрешение фотографий не включается автоматически. Возврат к 0.4.1 требует отдельной полной старой папки: её exe не открывает схему 4. Обратное слияние новых записей не обещается.

## Работа с исправленным диалогом и предметом

Выберите предмет в «Предметах» и нажмите переход к ДЗ. Он уже выбран в новой форме, в том числе до загрузки программ/работ. Существующие работы не меняют свой предмет при переключении экрана.

В одной работе сохраните и подтвердите решение. Для уточнения выберите «Продолжить диалог» и введите вопрос. Следующий запрос включает предыдущие реплики с их настоящими ролями. Ответы по старой версии остаются историческими; их нельзя считать проверкой исправленного решения. При отказе из-за длины сохранённая работа остаётся доступной; можно создать отдельную работу с нужным фрагментом.

Если предмет **старой** работы неверен, используйте форму «Создать исправленную копию» в её карточке. Выберите правильный предмет, затем подтвердите текст копии и проверьте заново. Это не переименование истории.

Черновики сохраняются при смене предмета в рамках текущего входа. «Сбросить сохранённый черновик» возвращает сохранённые данные. При несовпадении revision нативный слой отклоняет устаревшее сохранение; история другого пользователя не подставляется.
