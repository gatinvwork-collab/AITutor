# Tutor-AI 0.5.0a3 — исправления повторного QA

Дата: 28.10.2026. Предварительная Windows Portable-версия. Основание — [требования QA-050-04/05](qa-remediation-requirements-0.5.0a2-2026-10-28.md). Полная приёмка A01–A20/MVP не подтверждена.

## Причины и изменения

- **QA-050-04.** При автопаузе `Learning.tick()` очищал `assessment_active` до успешного checkpoint. Отказ `store.save()` откатывал SQL, но оставлял runtime без активной попытки. Теперь указатель и временная база публикуются после успешного сохранения. Повтор начисляет только допустимый интервал, включая границы idle 180 секунд и limit + 900 секунд; повторные отказы не двигают временную базу. Ошибка фоновой записи показывается постоянным уведомлением, которое снимается после успешного повторного tick. Конфликтующие занятия остаются запрещены.
- **QA-050-05.** Непустое уточнение заменяло инструкцию выбранного режима. Теперь фактический system message содержит текущий `check` / `hint` / `follow_up` и соответствующую инструкцию; вопрос ученика дополняет её. Пробельное уточнение использует инструкцию выбранного режима. Исторические режимы обозначены как метаданные прошлых вызовов и не заменяют текущее действие. Полный запрос проверяется на лимит 30 000 символов без усечения.

Прежние журналы не дописываются: сохранённый `body.intent` старого вызова не означает, что модель получила этот режим. При следующем запросе используются отдельно помеченные сведения о прошлом режиме. Сохраняются пары вопросов/ответов, ревизии, оригиналы и результаты. Старые предметы не переименовываются автоматически.

## Обновление с сохранением данных

1. Закройте все экземпляры приложения. Сохраните отдельную полную копию прежней Portable-папки: exe вместе с `app-data/`, включая вложения и резервные копии. Проверьте место, возможность записи и отсутствие блокировок файлов.
2. Поместите `dist/Tutor-AI-0.5.0a3.exe` рядом с прежней `app-data/` в тестовой копии. Запускать одновременно старую и новую версии с одной базой нельзя. Не объединяйте разные папки `app-data` вручную.
3. Войдите прежним профилем. Проверьте историю, фото, учебные подборки и настройки. После закрытия процесса диагностика требует явного продолжения; время выключенного приложения не начисляется.
4. После проверки используйте эту папку как новую Portable-установку. Исходную копию сохраните для возврата. Для возврата запустите старый exe со всей сохранённой старой папкой данных; не подменяйте им exe в уже изменённой базе.

**a2 → a3 и a1 → a3:** SQL-схема 4, контейнер AEAD 1, backup 1 остаются прежними. Массовой миграции/переоценки истории нет. **0.4.1 → a3:** действует существующая миграция 3 → 4 с зашифрованным снимком до преобразования. Exe 0.4.1 не открывает схему 4.

Потерянные старой версией интервалы времени не восстанавливаются по настенным часам и не начисляются задним числом. Разрешения облачной обработки/фотографий автоматически не включаются. Рабочие пользовательские данные при разработке не открывались; испытания выполнялись только на синтетических копиях.
