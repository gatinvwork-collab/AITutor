# Сохранённые старые имена — Tutor-AI 0.4.0

| Расположение | Причина | Проверка |
|---|---|---|
| `tutor_ai/service.py`: `aitutor-backup-key-v1`, `aitutor-backup-v1` | Байтовые идентификаторы AEAD старого протокола | Старые ручные/автоматические архивы, recovery и restore в регрессии |
| `tutor_ai/storage.py`: `aitutor-attachments-v1` | Вывод ключа старых оригиналов вложений | Побайтная расшифровка старого оригинала после переноса схем 1–3 |
| `.aitbackup`, фильтры и примеры расширения | Совместимый формат архивов | Создание и восстановление без смены расширения |
| `tests/exe_qa_031.py`, `tests/exe_qa_032.py`: прежние exe по умолчанию | Возможность повторить проверки исторических выпусков | Новый стенд `tests.exe_qa_040` передаёт путь нового exe явно |
| `tests/conftest.py`: псевдонимы `aitutor.*` | Неизменённые независимые QA-пробы импортировали прежний пакет | Псевдонимы существуют только в pytest-процессе; приложение их не поставляет |
| `tests/test_transfer_040.py`, `tests/gui_transfer_040.*` | Имена, сообщения и файлы синтетической старой установки | Проверяется сохранение исходного текста, а не его массовая замена |
| `tests/test_feedback_02.py`: старые backup AAD | Проверка совместимости прежнего формата | Восстановление архива прежней схемы |
| `docs/evidence/`, завершённые QA-отчёты, ADR и release notes до 0.4.0 | Неизменяемая история решений и фактических испытаний | Сравнение с Git до переименования; прежние ссылки остаются доступны |
| `docs/rename-tutor-ai-requirements.md`, описание перехода/совместимости в текущих документах | Исходное имя и исходный URL нужны для объяснения перехода | Новый origin проверяется отдельно; старый адрес проверяется на редирект |
| Старые exe, снимки, пользовательские данные, `.git` | История и возможность возврата; не область текстовой замены | Новая сборка имеет отдельные имя, номер и SHA256 |

Qt ApplicationName/OrganizationName теперь `Tutor-AI`. Настройки профилей хранятся в vault; WebView и кэш имеют явные Portable-пути, `QSettings` для настроек приложения не используется. Смена Qt-имён не перемещает пользовательские данные в системный профиль.
