# Прототип 0.3.2 — таймер и полнота импорта

Дата: 26.10.2026. Основания: [повторный QA](qa-report-0.3.1-retest-2026-10-26.md), [требования 0.3.2](qa-remediation-requirements-0.3.2.md). Заказчик выбрал отказ длинного импорта с предложением разбить задание.

## Изменения

- **QA-005:** изменение активного состояния публикуется после успешной записи ответа. При отказе завершения практика и диагностика остаются на последнем подтверждённом состоянии с работающим таймером. Временные курсоры не продвигаются при неуспешном checkpoint; повтор не теряет и не удваивает секунды. Форма сохраняет ответ и использует прежний operation ID при повторе того же содержимого.
- **QA-006:** pause/complete исторического занятия не отключают текущий таймер. Повтор завершения не переписывает дату окончания. Новое/возобновляемое занятие проверяет активные записи в хранилище, а не только указатель памяти. Desktop tick может восстановить обслуживание единственной активной записи при потере кэша указателя.
- **QA-007:** начисляется интервал до ближайшей границы — текущего момента, 180 секунд бездействия или остатка разрешённого времени. Задержанный на 600 секунд tick без новых действий начисляет максимум 180. Пауза, история и фоновый snapshot не продлевают учебную активность.
- **QA-008:** TXT/PY/CSV/PDF/DOCX с извлечённым текстом более 30 000 Unicode-кодовых точек отклоняются с предложением разбить работу. Частичная новая работа не сохраняется. Удалена скрытая обрезка PDF-страниц до 5 000 символов. Предел файла 8 MiB остаётся отдельным; ограничения PDF/DOCX сохранены.

Длина текста считается после декодирования и приведения переводов строк к LF. BOM не включается; emoji вне BMP считаются одной кодовой точкой, а не двумя единицами UTF-16. UI и нативная проверка согласованы. Если при декодировании UTF-8 заменены недопустимые байты, показывается отдельное предупреждение; такое извлечение не маркируется достоверным.

## Старые данные и обновление

SQL-схема остаётся **3**; формат шифрования и backup не меняется. Исторические секунды не пересчитываются по догадке. Для 0.1/0.2 сохранены прежние атомарные миграции; базы 0.3/0.3.1 открываются без массового преобразования.

Новые принятые файлы получают метаданные версии извлечения, длины, единицы измерения и статуса. Полный оригинал хранится зашифрованным. При новой обработке старого файла без этих метаданных оригинал проверяется заново. Если текст слишком длинный, новая проверка блокируется, а история остаётся доступной. Если извлечение допустимо, создаётся новая версия работы, полный текст показывается для повторного подтверждения; старые текст, оригинал, ответ ИИ и идентификатор сохраняются. При отсутствии оригинала предлагается прикрепить его заново.

Закройте старую версию, сохраните копию Portable-папки и поместите `AI-Tutor-0.3.2.exe` рядом с прежним `app-data/`. Повторная регистрация не нужна. Прежние исполняемые файлы сохранены отдельно.
