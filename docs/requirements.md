# Базовые требования MVP 1.0

Дата источника: 25.10.2026. Статус источника: проект ТЗ для согласования. Этот документ — выжимка и реестр трассировки, а не дословная копия ТЗ. При расхождении применяется исходный текст заказчика; изменение объёма требует отдельного решения.

Изменения для 0.2: по [результатам тестирования и последующему запросу реализации](user-feedback-requirements-0.2.md) математика 7-го класса разделена на алгебру/геометрию; разрешены открытые имена/роли для входа и сетевой адресный поиск. [Фактический объём](release-0.2.md) и [ADR](adr-0002-profiles-addresses-subjects.md) описывают ограничения этих изменений.

## Границы продукта

Дополнение 0.3 от 26.10.2026: родитель редактирует разрешённые поля своей анкеты, связанных детей и родителей с общим подтверждённым ребёнком. Это уточнение ACL относится только к анкетам; доступ к другим детям, секретам и полномочиям другого родителя не предоставляется. Ученик меняет регион, город и школу самостоятельно с локальным уведомлением каждого связанного родителя. Вводятся два дизайна с независимым цветовым режимом; существующие ученики при миграции получают «Современную». Пустые архивные предметы скрываются без удаления истории. Подробности: [спецификация 0.3](user-feedback-requirements-0.3.md), [реализация](release-0.3.md).

- Windows 10/11 x64, Portable, один исполняемый файл с ресурсами приложения; установленный WebView2 допускается.
- Русский язык, 7-й класс, алгебра, геометрия, информатика, физика; пилот до 20 учеников. Это уточнение исходного перечня предметов по FB-04.
- Две локальные роли: STUDENT и PARENT; связи многие-ко-многим.
- OpenAI, GigaChat, Qwen с OpenAI-совместимым режимом, локальный Ollama — обязательны.
- Все постоянные данные в `app-data/` рядом с фактическим `.exe`; база и конфиденциальные вложения зашифрованы.
- Учебные режимы: изучение, проверка ДЗ, диагностика. Экзамены исключены.
- Расширение на 1–11 классы, другие предметы и Linux предусмотрено архитектурой, но не входит в поставку MVP.
- P0 обязательно для приёмки. P1 включается по решению планирования; P2 остаётся в последующих релизах. Отсутствие отметки P0 у отдельных правил исходного ТЗ не означает разрешение их игнорировать.

## Поля модели знаний

`mastery_score`, `confidence`, `attempts_count`, `correct_count`, `hints_used`, `error_types`, `last_practiced_at`, `next_review_at`, `trend`. Оценка системы не является школьной отметкой. Формула расчёта и правила педагогической валидации пока не утверждены.

## Неподтверждённые решения

Сохраняются OPEN-01–OPEN-12 из ТЗ. До результатов PoC не утверждены стек, схема PIN-разблокировки, управление ключами нескольких родителей, STT/TTS, возможности конкретных моделей, минимальный ПК, источники контента, правила конкурирующих настроек и реализуемость срока. Правовые вопросы обработки данных детей и использования материалов должны быть закрыты до пилота; этот пакет не является правовым заключением.

## Готовность

Готовность определяется всеми 13 пунктами раздела 20 исходного ТЗ и AT-01–AT-38. Наличие интерфейса или адаптера без работающего сценария не является выполнением требования. Педагогическая эффективность оценивается по пилоту отдельно от технической приёмки.
