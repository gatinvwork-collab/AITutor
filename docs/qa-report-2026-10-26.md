# Протокол тестирования AITutor 0.3 — 26.10.2026

**Вывод:** приёмка пакета 0.3 не подтверждена. Найдены 4 открытых дефекта, включая раскрытие чужого отчёта после восстановления копии. [Реестр дефектов с воспроизведением](qa-bug-register-2026-10-26.md).

## Объект, основания и среда

Изучены требования 0.3 и 0.2, базовые требования, руководство, release notes, план приёмки, реализация Python/JS/CSS и существующие тесты. Проверялись реализованные функции desktop-прототипа; будущие возможности MVP не считались реализованными только по наличию требования.

Рабочая копия содержит незакоммиченные и неотслеживаемые файлы. Поэтому commit сам по себе не идентифицирует проверенный продукт. Commit, состояние Git, версии среды, SHA256 всех модулей приложения/UI и exe записаны в [environment-and-runs.json](evidence/qa-review-2026-10-26/environment-and-runs.json).

- Windows 11 x64, build 26300; Python 3.13.15; PySide6 6.12.0; pytest 9.1.1.
- Исходники: текущая рабочая копия AITutor 0.3.0.
- Portable: SHA256 `6e316d3eba7067f93d95deef446d79b6d1ae0f92716e8f9d178a28827a543f2f`.
- Использованы только синтетические семьи, временные хранилища в build и FakeProvider/HTTP mock. Рабочие app-data и dist/app-data не открывались.
- Код приложения, пользовательские данные и существующая проектная документация не исправлялись. Добавлены документы QA, воспроизводящие тесты и доказательства.

Нативный shell-инструмент оказался недоступен из-за ошибки запуска среды. Команды выполнены через терминал PyCharm. Постоянная настройка Git safe.directory не менялась: для чтения commit/status использовано исключение только в конкретном вызове Git.

## Границы и невыполненные проверки

1. Реальные ответы OpenAI/GigaChat/Qwen/Ollama, фактическая авторизация и токены — blocked: проверка выполнялась без действующих тестовых ключей/подготовленного сервера. Контрактные mock-тесты не заменяют AT-10–13.
2. Интернет-поиск Photon, полнота реальных адресов и недоступность внешнего сервиса — проверены фикстуры/валидация; реальная интеграция не подтверждена.
3. TTS системным русским голосом, микрофон, OCR/vision/STT: TTS не проверен на слух; OCR/диктовка в этой версии заявлены как нереализованные и не включены в список ошибок реализованного функционала.
4. Целевой второй ПК, чистая Windows без dev runtime, read-only папка, полные показатели производительности и отказ питания не проверены.
5. Контраст 4.5:1/3:1 на худшем фоне, весь keyboard-only маршрут, фактическое отсутствие поддержки blur, очень большие таблицы и полный корпус HW-001 требуют дополнительной приёмки.
6. Функциональное тестирование выполнялось преимущественно из исходников. Для exe выполнен отдельный smoke; тождество встроенных в exe исходников рабочей копии не доказано.
7. AT-01–AT-38 не объявляются полностью пройденными. Предыдущие протоколы разработчика не использовались как доказательство нового запуска.

## Передача программисту и повторный запуск

Приоритет: устранить QA-001 до приёмки; затем QA-002/QA-003 и QA-004. Полные предусловия, шаги, фактический/ожидаемый результат, локализация и критерии перепроверки находятся в [реестре](qa-bug-register-2026-10-26.md).

```powershell

.\.venv\Scripts\python.exe -X utf8 -m pytest docs/evidence/qa-review-2026-10-26/test_exploratory.py -q --basetemp=build/qa-repeat-extra

```

Первые три команды достаточны для повторения основной регрессии и четырёх зарегистрированных дефектов. До исправления exploratory pytest и GUI завершаются с кодом 1 — это ожидаемый результат воспроизведения ошибок. Все базы изолированы; не направлять эти пробы на пользовательский app-data.

После исправления повторить воспроизводящие тесты, штатную регрессию и проверки восстановленного клиентского состояния, затем закрыть перечисленные ограничения отдельным протоколом.
