## Ограничения среды и завершения

**REN-04:** попытка физически переименовать открытый каталог `AITutor` отклонена Windows: файл занят другим процессом. Поэтому создан самостоятельный рабочий каталог `Tutor-AI` с Git-историей, текущими изменениями, постоянными файлами и отдельным venv. Исходная папка сохранена; она не удалялась и не объявляется переименованной. Для работы следует открыть новый каталог в IDE; его `.idea` ссылается на новый venv. Закрытие удерживающего старую папку процесса и окончательная уборка старого каталога остаются средовым шагом. Переподключение уже открытого проекта PyCharm автоматически не выполнялось.

Windows UI-помощник не запустился (`setup refresh had errors` / `trusted Node process exited unexpectedly`), в том числе после сброса. Поэтому системный выбор папки в **собранном exe** отдельно не автоматизирован. Полный сценарий B проверен нативно и в настоящем WebView исходной версии с тестовым ответом нативного QFileDialog; фактический перенос через готовый exe не объявляется отдельно принятым. Работоспособность упакованного приложения, прежняя история и схема 1/2/3 проверены exe-стендом через Qt CDP.

Реальное отключение питания, сон Windows, физическое заполнение диска, второй компьютер, полнота OCR/диктовки, реальные внешние сервисы и полная доступностная приёмка не проверялись. Отказы записи/места/отмена моделировались детерминированно. Нельзя считать все RREN-01–22 полностью аппаратно принятыми по этому протоколу.
